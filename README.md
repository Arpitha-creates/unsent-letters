# Unsent — letters you'll never send

A quiet place to write the letters you keep drafting in your head and never send. Each one becomes a folded paper that drifts gently in the space, waiting whenever you want to read it again.

## What it does
- Write letters with an optional recipient, a subject and a body
- Each letter appears as a softly drifting sheet of folded paper with a wax seal
- Tap any letter to read it in full
- "Let it go" to delete one for good
- No accounts, no sync, no sharing — it's yours alone

## Run it
Download `index.html` and open it in any modern browser, or enable GitHub Pages. No build step, no dependencies.

## Your data
Letters are stored only in your browser's local storage on this device. Nothing is ever uploaded.
